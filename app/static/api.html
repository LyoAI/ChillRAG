Swagger ↗

One card per endpoint, each fired exactly the way the vendor client fires it — including where parameters live (query string, multipart, bare JSON array). Sign in first: the page is served by the same service, so the browser holds the space-auth cookie and sends it automatically.

POST /space/api/passport/login

Exchanges credentials for the space-auth cookie every other endpoint requires. The field is passwd, not password.

or press Enter in the password field
GET /space/api/service/asset-file/resource

Lists sources. Not part of the vendor protocol — this service adds it for its own UI — but it saves you hunting for a source_id. Also fills the corpus selector above.

needs any signed-in account
PUT /space/api/service/asset-file/resource

Creates a source — a folder under the materials directory — and returns its source_id. Needs an admin account.

letters, digits, - and _; no slashes
POST /space/api/service/asset-file/web-upload?sourceId=…

Multipart upload into the selected corpus. Parsing, chunking and indexing run in the background, so the response is just a list of file ids — poll Ingest status until they read finish.

uses the corpus selector above
POST /space/api/service/asset-file

Status for a list of file ids. The body is a bare JSON array ([123]), not an object.

pending / running / finish / failed
POST /space/api/service/llmapi/ht/normal_rag_recall_without_doc_group

Retrieval. All parameters go in the query string, not the body. origin_ids filters by file id, so leave it empty to search the whole source — a non-empty value that matches nothing comes back as an empty list.

the union of the requested types, ranked
GET /space/api/service/asset-file/segments/{file_id}

Whole-document readback. Each segment.content is a JSON string holding {"content": …} — decoded below for readability.

a 40-page report is a large response
POST /space/api/service/sse/llmapi/ht/text/post-answer

Streamed answer (SSE). source_category_filter is a string containing a JSON object keyed by source id, and exactly one source is accepted. Newlines and spaces travel as [new_line] / [whitespace], and the answer follows an empty <strong> preamble — all decoded below.

source_category_filter (built from the corpus selector)
runs the agent — this one takes seconds
every response is the vendor envelope — {"code", "msg", "data"}
